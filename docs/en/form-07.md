### Instructions for using Form No. 07-VDS:
**(1)** State the name of the Court issuing the decision; if it is a district-level People's Court, provincial city People's Court, or town People's Court of a province or centrally run city, clearly state which district-level, provincial city, or town People's Court of which province or centrally run city (for example: Thuong Tin District People's Court, Hanoi City); if it is a provincial or centrally run city People's Court, state that provincial (city) People's Court (for example: Ha Nam Provincial People's Court).

**(2)** The first box states the number, the second box states the year of issuance of the decision.

**(3)** If resolving only a complaint, write "RESOLUTION OF COMPLAINT"; if resolving only a recommendation, write "RESOLUTION OF RECOMMENDATION".

**(4)** Depending on each case, specifically state the points and clauses of Article 194 of the Civil Procedure Code.

**(5)** If the complainant is an individual, clearly state full name and address of place of residence and place of work (if any) of that person; if it is an agency or organization, state the name and headquarters address of that agency or organization (as stated in the petition). If the complainant is a representative by operation of law, after the full name write "- is the representative by operation of law of the person with the right to complain" and clearly state the full name of the person with the right to complain; if the complainant is an authorized representative, write "- is the authorized representative of the person with the right to complain under the power of attorney established on…….." and clearly state the full name of the person with the right to complain; where only the recommendation of the People's Procuracy is being resolved, do not state this content.

**(6)** State the number, symbol, day, month, year of the recommendation document and the name of the People's Procuracy issuing the recommendation document; where only a complaint is being resolved, do not state this content.

**(7)** Depending on each case provided for in Clause 1, Article 364 of the Civil Procedure Code, state the specific contents.

**(8)** Depending on each case, state the result of resolving the complaint and recommendation in accordance with the provisions at Point a or Point b, Clause 4, Article 194 of the Civil Procedure Code.

**(9)** State the full name of the complainant (for example: Mr. Nguyen Van A).

**(10)** State the name of the Court one level directly above the Court issuing the Decision on Resolution of Complaint or Recommendation regarding Return of Petition.
